# 운세 계산 로직 (이름 + 생년월일 → 결과)

## 1. 띠 계산
```
띠_index = (생년 - 4) % 12
```
`zodiac_animals.json`의 `index`와 매칭 (0:쥐 … 11:돼지)

## 2. 오행 계산
```
마지막자리 = 생년 % 10
```
`five_elements.json`의 `천간표`에서 매칭되는 오행을 사용

## 3. 시드값 생성 (이름 + 생년월일 → 점수)
매일 다른 "오늘의 운세"를 주고 싶다면 **오늘 날짜도 시드에 포함**, 평생 고정된 결과를 주고 싶다면 **생년월일+이름만** 사용.

```
seed_source = 이름(문자열) + 생년월일(YYYYMMDD) + [선택: 오늘날짜(YYYYMMDD)]
seed = 문자열의 각 글자 유니코드 값을 합산 (또는 간단한 해시함수, 예: djb2 / 문자코드 합)
score = seed % 100   // 0~99 사이 값
```

- 이름의 한글 글자 수, 초성 유무 등은 크게 중요하지 않음 — 유니코드 값 합만으로도 충분히 고르게 분산됨.
- 카테고리(종합운/애정운/재물운/건강운/직장학업운)마다 **다른 오프셋**을 더해 서로 다른 점수를 내면 카테고리별 운세가 겹치지 않음.
  ```
  종합운_score  = (seed + 0)  % 100
  애정운_score  = (seed + 17) % 100
  재물운_score  = (seed + 34) % 100
  건강운_score  = (seed + 51) % 100
  직장학업운_score = (seed + 68) % 100
  ```

## 4. 등급 매핑
`fortune_templates.json`의 `등급.scoreRange`에 따라 점수를 대길/길/평/주의 중 하나로 변환

## 5. 문구 선택
해당 카테고리 + 등급의 문구 배열에서 `seed % 배열길이` 인덱스로 하나를 결정적으로 선택
(같은 이름+생년월일이면 항상 같은 문구가 나오도록 랜덤이 아닌 시드 기반 선택 권장)

## 6. 플레이스홀더 치환
문구 안의 `{name}`, `{animal}`, `{keyword}`, `{element}`, `{color}`, `{number}`, `{direction}` 등을
각각 이름, 띠 이름, 띠 keyword, 오행 이름, 오행 color/number/direction 값으로 치환

## 참고: 생년월일 유효성 체크
- 연도: 1900~현재연도 사이만 허용
- 월: 1~12, 일: 1~31 (윤년/월별 일수 검증 권장)
